# Artwork and fonts

The Android app and widget include unmodified Clash of Clans item artwork for identifying upgrades. Images are bundled for offline use. See [artwork-sources.json](artwork-sources.json) for each file's source URL.

- Game artwork and characters: © Supercell Oy.
- Asset distribution source: [ClashKingAssets](https://github.com/ClashKingInc/ClashKingAssets), original WebP files. No extractor or library code from that repository is included.
- Usage of Supercell artwork is governed by [Supercell's Fan Content Policy](https://supercell.com/en/fan-content-policy/), not the application's MIT source license. The assets are not being relicensed under MIT. Keep the unofficiality notice and attribution when redistributing this fan app.
- Artwork is illustrative; upgrade labels and levels come from the imported village. Generic building illustrations may represent a different building level. Unknown items use a village illustration.
- Typeface: Barlow Condensed Bold by Jeremy Tribby. Distributed under the SIL Open Font License; the full license is bundled alongside the font in `app/src/main/assets/fonts/OFL.txt`.
- Interface icons, backgrounds, and layouts are original application assets.

In-app notice: “This material is unofficial and is not endorsed by Supercell. For more information see Supercell's Fan Content Policy.”

README screenshots in `docs/screenshots/` are captured from the Android emulator using demo village data. They contain the same Supercell artwork and retain the attribution above.
